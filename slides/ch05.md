# 5.1 云计算的未来趋势

## 云计算下一步往哪里走

- **边缘计算与物联网**：计算下沉到设备身边
- **人工智能 + 云**：云提供算力、数据和平台
- **Serverless**：只写函数，不管服务器
- **大模型 + 云**：训练、推理都离不开云上 GPU 集群

## 边缘计算：把计算搬到身边

- 在靠近设备、数据源头的一侧就近计算
- **缩短延迟**：自动驾驶等不能等云端回复
- **节省带宽**：在本地先筛选，只上传有用的数据
- **支持离线**：断网也能继续工作
- 与云计算互补：**云边协同**

## 动画：边缘计算与云端计算对比

!sim edge-latency
- 调整设备数量、数据量和网络延迟
- 比较“全部上云”和“边缘先处理”的延迟与带宽

## 边缘计算的应用与方案

- 应用：车联网、智慧交通、智慧农业、智慧医疗
- 运营商：**MEC**（移动边缘计算），2014 年由 ETSI 提出
- 云服务商：阿里云 Link Edge、百度 OpenEdge、华为开源 **KubeEdge**

## 人工智能与云计算

- 云提供存储、**GPU 算力**和部署平台
- 人工智能从数据中提取价值
- 应用：智能客服、物流、金融、城市、制造、医疗
- 两者互补，协同工作

## Serverless：无服务器计算

- 开发者只写**函数**，服务器交给云平台
- 平台自动伸缩，**按调用计费**，不调用不花钱
- 2014 年 **AWS Lambda**：首个商业化 FaaS
- 挑战：**冷启动**、可移植性、可观测性

::: notes
冷启动：函数一段时间没被调用，再次调用时要重新创建运行环境，响应变慢。阿里云函数计算、腾讯云云函数在 2017 年推出。
:::

!sim serverless-billing
- 拖动每天的调用量
- 找到“函数计算更省钱”和“云服务器更省钱”的分界点

## 大模型与云计算

- 大模型训练要数千块 GPU，企业通过**云服务**获取算力
- 云提供 GPU 集群、分布式存储、弹性部署
- 云厂商把大模型做成 API 服务（MaaS）
- 趋势：云边端协同、多云混合云、绿色计算、行业大模型

# 5.2 职业发展与认证

## 云计算相关岗位

| 岗位 | 主要工作 |
|---|---|
| 云架构师 | 设计云上系统的整体方案 |
| 云运维工程师 | 保证云上系统稳定运行，监控、排障 |
| DevOps 工程师 | 打通开发和运维，自动化部署 |
| 售后工程师 | 帮客户解决产品使用中的问题 |

::: notes
专科毕业生最常见的起点是云运维工程师。DevOps 工程师关注部署频率和故障恢复速度，传统运维更关注可用性和故障预防。
:::

## 学生应具备的技能

- **Linux**：常用命令、Shell 脚本
- **网络基础**：TCP/IP、VPC、CIDR 地址规划
- **虚拟化与容器**：KVM、Docker、Kubernetes
- **云平台**：ECS、对象存储、负载均衡
- **自动化运维**：Terraform、Ansible

## 云计算认证

| 厂商 | 入门 | 进阶 |
|---|---|---|
| 阿里云 | ACA | ACP（专业级） |
| 华为 | HCIA-Cloud Computing | HCIP、HCIE |
| 深信服 | SCCA-C（适合应届生） | SCCP-C、SCCE-C、SCCM-C |
| AWS | Cloud Practitioner（基础级） | 助理级、专业级 |

::: notes
认证有有效期，需要按要求更新。先了解体系，不必记住每个认证名称。另有各平台的微认证，适合入门体验。
:::

## 职业道德：做人做事的底线

- **诚实守信**：如实报告故障和问题
- **保守秘密**：客户数据只在授权范围内使用
- **遵守法律**：不越权访问、不破坏数据
- 处理病历等敏感数据：授权访问、加密存储和传输

## 反面案例：删库

- 工程师离职后，账户权限仍然有效
- 恶意删除银行的重要业务数据
- 另一案例：程序员删库被判刑
- 教训：企业严格管理权限的**分配与回收**，个人守住法律底线

# 本章实验

## 实验 5-1 ☆ 在函数计算上部署第一个函数

- 在阿里云函数计算中创建一个 Python 函数
- 输入每小时价格和每天运行时长，函数返回费用
- 体会：不用买服务器，按调用计费
- 观察第一次调用和之后调用的耗时差别（冷启动）

# 本章小结

## 本章要点

- 边缘计算缩短延迟、节省带宽，与云形成云边协同

- Serverless 只写函数、按调用计费，挑战是冷启动
- 岗位：云架构师、云运维、DevOps、售后；从云运维起步
- 诚实守信、保守秘密、遵守法律是从业底线
