# 3.1 主流云平台入门

## 主流云平台

| 类别 | 平台 |
|---|---|
| 国内公有云 | 阿里云、腾讯云、华为云 |
| 国外公有云 | 亚马逊 AWS |
| 私有云 | 信服云、H3C 云 |

## 账号注册与管理

- 注册 → **实名认证** → 开通服务
- 主账号权限很大，日常不直接使用
- 给团队成员创建**子账号**
- 按需授予**最小权限**，离职及时回收

::: notes
注册操作在实验 1-1 已经做过，这里重点讲子账号和最小权限原则，第 5 章“删库”案例会再次呼应。
:::

## 怎么选计费模式

| 计费模式 | 适合 |
|---|---|
| 按量付费 | 波动大、时间短的业务 |
| 包年包月 / 预留实例 | 长期稳定运行的业务 |
| 抢占式（竞价）实例 | 可以中断的任务，如批量计算 |

::: notes
抢占式实例价格低，但可能被回收，不能跑银行核心交易这类不能中断的系统。
:::

## 成本优化的几个办法

- 选对计费模式
- 按实际负载调整配置，不买“大马拉小车”
- 用好新用户优惠和资源包
- 存储**生命周期规则**：冷数据转到低价存储

# 3.2 IaaS 层服务

## 云服务器的七个环节

- **创建**、**选择实例**：地域、规格、镜像、网络
- **登录**：Linux 用 SSH，Windows 用远程桌面
- **监控**：CPU、内存、带宽
- **扩缩容**：升降配置、增减台数
- **安全**：安全组、密钥、补丁
- **费用管理**：续费、释放、账单

## 云存储：以对象存储为例

- 创建存储桶，选择地域和存储类型
- 上传、下载、分享文件
- 默认**私有**，分享用临时链接
- 同步与备份：本地文件自动同步到云端

## 云数据库

- 有 MySQL、SQL Server、PostgreSQL 等版本
- 数据库软件由云平台安装、备份、升级
- 用户只管建库、建表、用数据
- 严格说更接近 PaaS，教材放在 IaaS 一节

# 3.3 PaaS 层服务

## 消息队列：快递驿站

- 生产者把消息放进队列
- 消费者按自己的节奏来取
- 两边不必同时在线：**异步解耦**
- 削峰填谷：生产太快时先存起来慢慢处理

## API 网关：大楼前台

- 所有请求先到网关
- 统一入口、**路由**到后端服务
- **鉴权**：验证访问者身份
- **限流**：防止请求过多压垮服务

## 应用托管与弹性伸缩

- **容器服务**：管理一大群容器，如阿里云 ACK
- **函数计算**：只写代码，不管服务器，按调用计费
- **弹性伸缩**：按规则自动增减实例

# 3.4 SaaS 层服务

## 常见的 SaaS 应用

| 类别 | 例子 |
|---|---|
| 协作工具 | 钉钉、飞书、企业微信 |
| CRM | Salesforce、纷享销客 |
| ERP | SAP S/4HANA Cloud、明源云 ERP |
| 项目管理、人力资源、在线教育 | 各类在线平台 |

## 模型即服务 MaaS

- 把训练好的大模型做成服务
- 通过 API 调用，按调用量付费
- 不用自己买 GPU、训练模型
- 框架三层：**模型平台层、模型服务层、模型应用开发层**

# 3.5 自动化运维工具

## Terraform 和 Ansible

- **Terraform**：用代码**创建**云资源（基础设施即代码）
- **Ansible**：通过 SSH 批量**配置**服务器
- 两者结合：Terraform 建机器，Ansible 装软件

## CI/CD 流水线

- **持续集成 CI**：提交代码后自动构建、测试
- **持续交付 / 部署 CD**：自动发布到测试或生产环境
- **蓝绿部署**：新旧两套环境，出问题立刻切回
- 云上实现：AWS CodePipeline、Azure DevOps、阿里云云效
