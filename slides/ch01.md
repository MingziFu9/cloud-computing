# 1.1 云计算概述

## 云计算的定义

- 通过网络**按需**获取可配置的计算资源
- 资源来自一个共享的**资源池**
- 快速提供、快速释放，管理工作很少
- 按**使用量**付费，像水电一样

::: notes
定义来自美国国家标准与技术研究院（NIST）。不必背原文，抓住“网络、按需、资源池、按量付费”四个关键词。
:::

## 云计算的 5 个主要特点

- **宽带网络连接**：随时随地通过网络访问
- **按需自助服务**：自己在网页上开通，不用找人
- **资源池化、与位置无关**：不必知道在哪个机房
- **弹性扩展**：忙时多用，闲时少用
- **服务可被测量**：用多少、计多少

::: notes
另有 3 个新特点：支持异构资源、支持异构多业务、通算与智算统一管理。新特点了解即可。
:::

- 对比“自建机房”和“弹性伸缩”的费用

## 三项核心技术

| 技术 | 一句话 | 打个比方 |
|---|---|---|
| 虚拟化 | 把一台物理机“切”成多台虚拟机 | 一栋楼隔成多套公寓 |
| 分布式计算 | 把大任务分给很多台机器 | 1 万份试卷分给 100 个老师改 |
| 资源调度 | 决定资源给谁、放在哪里 | 停车场安排车位 |

::: notes
这三项技术第 2 章还会细讲，这里只要知道“云靠什么撑起来”。
:::

## 动画：资源调度装箱

!sim bin-packing
- 把虚拟机“装”进物理服务器
- 装得越满，浪费越少
- 调度要兼顾利用率和可靠性

## 三种服务模式：用户管多少

- **IaaS**（基础设施即服务）：租服务器，自己装系统和软件
- **PaaS**（平台即服务）：只管自己的程序和数据
- **SaaS**（软件即服务）：打开就用，什么都不用管
- 从 IaaS 到 SaaS，用户管得越来越少

::: notes
用“毛坯房、精装房、酒店”打比方：IaaS 是毛坯房，PaaS 是精装房，SaaS 是酒店。
:::

## 动画：服务模式责任分层

!sim service-layers
- 切换 IaaS / PaaS / SaaS
- 看哪些层由用户负责，哪些由云服务商负责
- 无论哪种模式，**账号和数据**都要用户自己管好

## 服务模式举例

| 服务模式 | 典型产品 | 用户负责 |
|---|---|---|
| IaaS | 阿里云 ECS、对象存储 OSS | 操作系统及以上 |
| PaaS | 云数据库、容器服务、函数计算 | 应用和数据 |
| SaaS | 钉钉、飞书、在线文档 | 账号和数据 |

## 四种部署模式：谁拥有、谁使用

- **公有云**：云服务商建设，向公众开放
- **私有云**：一个组织独享，放在自己可控的机房
- **混合云**：私有云 + 公有云，核心数据放私有云
- **社区云**：几个有共同需求的组织共享，如政务云
- 变种：托管云、互联云、驻地云等

::: notes
社区云在国内也叫团体云、行业云。驻地云是云服务商把平台部署到用户机房、由服务商运维。
:::

## 云计算的应用场景

- **政务**：政务云，数据共享、业务协同
- **电商**：“双 11”流量洪峰靠弹性扩容
- **教育**：在线课堂、学习平台
- **医疗**：电子病历、影像共享
- **金融**：高可靠的业务系统和数据处理

# 1.2 云计算的发展

## 云计算从哪里来

- 1961 年：有人提出“像用水用电一样用计算”
- 虚拟化技术让一台机器能跑多个系统
- 2006 年：亚马逊推出 EC2 和 S3，云计算成为生意
- Docker、Kubernetes 带来云原生
- 今天：大模型跑在云上

::: notes
不必背年份，记住几个转折点：虚拟化、亚马逊 EC2/S3、Docker 和 Kubernetes、大模型。
:::

## 三个发展阶段

| 阶段 | 关键词 | 特点 |
|---|---|---|
| 云计算 1.0 | 虚拟化 | 把物理资源变成虚拟资源 |
| 云计算 2.0 | 服务化、自动化 | 资源自助申请、自动分配 |
| 云计算 3.0 | 微服务化、智能化 | 云原生、云 + 大数据 + 人工智能 |

## 两个发展趋势

- **终端轻盈化**：计算放到云上，终端越来越轻
- **云 + 大数据 + 人工智能**：三者融合
- 算力成为像水电一样的基础设施
