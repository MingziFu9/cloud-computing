# 2.2 分布式存储技术

## 连锁超市的仓库

- 一块硬盘装不下，坏了还会丢数据
- 分布式存储：把数据切成小块，分散到很多台服务器
- 每块再多存几份
- 一个仓库失火，别的仓库还有货

## 分布式存储的基本特征

- **数据分片**：大文件切成小块分散存放
- **冗余**：多副本或纠删码，坏一台不丢数据
- **一致性**：各副本的数据保持一致
- **故障恢复**：自动发现故障并补齐副本
- **动态扩展**：加机器就能扩容

## 多副本与纠删码

| 方式 | 做法 | 空间占用 | 特点 |
|---|---|---|---|
| 三副本 | 每块数据存 3 份 | 1 TB 占 3 TB | 简单，恢复快 |
| 纠删码 | 数据块 + 校验块 | 远少于三副本 | 省空间，计算多 |

## 三种存储类型

| 类型 | 打个比方 | 适合 |
|---|---|---|
| 对象存储 | 停车场取车牌，凭“对象名”存取 | 图片、视频、备份 |
| 文件存储 | 共享文件夹，有目录树 | 多台机器共享文件 |
| 块存储 | 一块“网络硬盘” | 数据库、虚拟机磁盘 |

- **Ceph**：统一分布式存储，同时提供对象、块、文件三种接口
- **HDFS**：Hadoop 的分布式文件系统，适合大文件、批量处理

# 2.3 分布式计算技术

## 1 万份试卷怎么改

- 一个老师改要一个月
- 分给 100 个老师同时改，一天改完
- 最后把分数汇总
- 分布式计算：**拆任务 → 并行算 → 合结果**

## 机器之间怎么协作

- **进程间通信**：管道、消息队列、共享内存等
- **远程过程调用 RPC**：像调用本地函数一样调用别的机器
- **时间同步**：各台机器“对表”
- **死锁和超时**：互相等待时要有超时机制

::: notes
共享内存是最快的进程间通信方式，多个进程直接访问同一块内存。抓住“谁和谁通信、用什么方式”即可。
:::

## MapReduce 的四个阶段

- **分片**：把输入数据切成多份
- **Map**：每份数据各自处理，输出（键, 值）
- **Shuffle**：同一个键的结果送到同一个 Reduce
- **Reduce**：对同一个键的值汇总

## 动画：MapReduce 词频统计

!sim mapreduce-wordcount
- 一步一步执行分片、Map、Shuffle、Reduce
- 观察“同一个词”最后落到哪个 Reduce

## Spark：把中间结果放在内存里

- MapReduce 每一步的中间结果都写硬盘
- Spark 把中间结果放在**内存**中
- 迭代计算（如机器学习）快得多
- 还支持流计算、SQL 查询等

# 本讲小结

## 本讲要点

- 分布式存储靠分片、冗余、一致性、故障恢复、动态扩展
- 对象存储存海量文件，文件存储共享目录，块存储给数据库
- 分布式计算把大任务拆给多台机器并行完成
- MapReduce：分片 → Map → Shuffle → Reduce
- Spark 把中间结果放在内存，更适合迭代计算
