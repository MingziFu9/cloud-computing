## 一栋楼隔成很多套公寓

- 物理服务器 = 一栋大楼

# 2.1.1 虚拟化的架构与类型

## 虚拟化的三个角色

- **主机**：真实的物理服务器
- **虚拟机**：在主机上“虚拟”出来的计算机，有自己的操作系统
- **Hypervisor**（虚拟机管理程序）：分配 CPU、内存、磁盘给各台虚拟机

## Hypervisor 的两种类型

| 类型 | 装在哪里 | 代表 | 适合 |
|---|---|---|---|
| 原生型（裸机型） | 直接装在硬件上 | VMware ESXi、KVM | 数据中心、云平台 |
| 宿主型（托管型） | 装在 Windows / Linux 上 | VMware Workstation | 个人电脑上学习、测试 |

## 全虚拟化与半虚拟化

- **全虚拟化**：客户操作系统不用改，不知道自己在虚拟机里
- **半虚拟化**：修改客户操作系统，让它“知道”自己是虚拟机
- 半虚拟化减少开销、性能更好，但要改系统
- 现在 CPU 自带硬件虚拟化功能，全虚拟化也很快

## 四类虚拟化

- **计算虚拟化**：CPU、内存的虚拟化
- **网络虚拟化**：虚拟交换机、虚拟网络
- **存储虚拟化**：把很多块硬盘变成一个存储池
- **桌面虚拟化**：桌面运行在服务器上（2.6 桌面云）

# 2.1.2 三种代表产品

## VMware、Docker、KVM

| 产品 | 类别 | 特点 |
|---|---|---|
| VMware | 虚拟机 | 商业软件，企业数据中心常用 |
| KVM | 虚拟机 | Linux 内核模块，开源，很多公有云在用 |
| Docker | 容器 | 打包应用和运行环境，启动快 |

## 虚拟机和容器的区别

- 虚拟机：每台都有**完整的操作系统**
- 容器：**共享宿主机内核**，只打包应用和依赖
- 容器更轻：体积以 MB 计，秒级启动
- 虚拟机隔离更彻底，可以跑不同的操作系统

## Docker 的三个基本概念

- **镜像**：打包好的、只读的应用模板
- **容器**：由镜像创建的运行实例，一个镜像可以创建多个容器
- **仓库**：存放和分发镜像的地方，如 Docker Hub

::: notes
类比：镜像像安装光盘，容器像装好并运行起来的程序，仓库像应用商店。
:::

# 2.1.3 虚拟机的使用

## 创建、快照、迁移

- **创建虚拟机**：选 CPU、内存、磁盘、操作系统镜像
- **快照**：保存某一时刻的状态，出问题可以回滚
- **迁移**：把虚拟机从一台主机搬到另一台
- **热迁移**：搬运时业务几乎不中断

# 本讲实验

## 实验安排

| 实验 | 内容 | 环境 |
|---|---|---|
| 2-1 ★ | 创建云服务器并打快照 | 阿里云 ECS |
| 2-2 ★ | 用 Docker 运行一个网站 | 装有 Docker 的电脑或云服务器 |

## 实验 2-2 的关键命令

```bash
docker pull nginx:1.27-alpine                          # 从仓库拉取镜像
docker run -d --name web -p 8080:80 nginx:1.27-alpine  # 用镜像启动容器
docker ps                                              # 查看正在运行的容器
docker stop web && docker rm web                       # 停止并删除容器
```

::: notes
-d 后台运行，-p 8080:80 把主机的 8080 端口映射到容器的 80 端口。浏览器打开 http://IP:8080 看到 Nginx 欢迎页即成功。
:::

# 本讲小结

## 本讲要点

- Hypervisor 把一台物理机分成多台虚拟机
- 原生型装在硬件上，宿主型装在操作系统上
- 容器共享宿主机内核，比虚拟机更轻、启动更快
- VMware、KVM 是虚拟化代表，Docker 是容器代表
- 快照用于回滚，迁移用于在主机之间搬运
