## 实验 5-1 ☆ 在函数计算上部署第一个函数 { #5-1 }

**实验目的**

1. 完成“写函数 → 部署 → 触发 → 看日志和费用”的 Serverless 全流程，体会 [5.1.3](5-1.md#513) 所说的“无须管理服务器”；
2. 观察冷启动：函数一段时间没被调用后，第一次调用会慢一些；
3. 对照动画“Serverless 与云服务器费用对比”，理解按调用次数和执行时间计费。

**实验环境**

- 运行环境：**云算力**。阿里云函数计算 FC（新用户通常有免费试用额度，以官网为准），只需浏览器。
- 编者实测：函数代码 `labs/ch05/lab5_1_fc/index.py` 已在本机 Python 3 中模拟调用验证；阿里云控制台部分为待实测。
- 费用：免费额度内 0 元。

**实验数据**：函数代码复用实验 3-3 的“云服务器月费计算”逻辑，输入单价和每天使用时长，返回月费。

**实验步骤与代码**

1. **开通服务**。登录阿里云控制台，搜索“函数计算 FC”，按提示开通。
2. **创建函数**。在函数计算控制台选择“创建函数”→“事件函数”，函数名称填 `monthly-cost`，运行环境选 Python 3.10（或页面提供的较新版本），代码上传方式选“在线编辑”，内存保持默认，其他设置保持默认。
3. **粘贴代码**。把在线编辑器中 `index.py` 的内容替换为下面的代码（完整代码见 `labs/ch05/lab5_1_fc/index.py`），点“部署”：

    ```python
    import json
    import time

    COLD_START_AT = time.time()   # 这行只在函数实例第一次启动（冷启动）时执行


    def handler(event, context):
        start = time.time()
        try:
            data = json.loads(event or b"{}")
        except ValueError:
            data = {}
        price = float(data.get("price_per_hour", 0.5))
        hours = float(data.get("hours_per_day", 24))
        result = {
            "monthly_cost": round(price * hours * 30, 2),
            "instance_age_seconds": round(start - COLD_START_AT, 1),
            "duration_ms": round((time.time() - start) * 1000, 3),
        }
        return json.dumps(result, ensure_ascii=False)
    ```

4. **测试函数**。点“测试函数”，在测试参数里填入事件内容：

    ```json
    {"price_per_hour": 0.5, "hours_per_day": 4}
    ```

    执行结果中应看到 `"monthly_cost": 60.0`。在执行结果页还可以看到本次调用的**执行时长**和**计费时长**。
5. **观察冷启动**。连续测试两次，比较执行时长和 `instance_age_seconds`：第二次通常更快，`instance_age_seconds` 变大，说明复用了同一个函数实例（热启动）。等待 10 分钟以上不调用，再测试一次，观察时长是否变长、`instance_age_seconds` 是否又接近 0。
6. **查看日志和监控**。在函数详情页的“日志”“监控指标”中查看调用次数、执行时长和错误次数。
7. **（选做）加 HTTP 触发器**。在“触发器”页创建 HTTP 触发器，用浏览器或 `curl` 发送 POST 请求调用函数。
8. **清理**。实验结束后删除触发器和函数。

!!! warning "待实测"
    编者环境无法访问阿里云控制台，步骤 1、2、4～8 依据阿里云函数计算公开文档编写，菜单名称和 Python 版本可能调整；任课教师上课前请实测并补充截图。函数代码已在本机模拟调用验证。

**运行结果**

在本机用 `python index.py` 模拟两次调用（间隔 1 秒）的输出：

```text
{"monthly_cost": 60.0, "instance_age_seconds": 0.0, "duration_ms": 0.038}
{"monthly_cost": 360.0, "instance_age_seconds": 1.0, "duration_ms": 0.106}
```

第二次调用的 `instance_age_seconds` 为 1.0，说明两次调用在同一个进程中完成，相当于函数计算的“热启动”。

**常见问题排查**

| 现象 | 原因与处理 |
|---|---|
| 执行结果报 `JSONDecodeError` 或返回默认值 | 测试参数不是合法的 JSON，注意使用英文双引号。 |
| 报 `handler not found` | 函数入口应为 `index.handler`，即文件名 `index.py` 中的 `handler` 函数。 |
| 修改代码后结果没变化 | 修改后要先点“部署”，再测试。 |
| 提示服务未开通或欠费 | 检查函数计算是否已开通、免费额度是否用完。 |

**思考与练习**

1. 本实验中，你有没有选择服务器的 CPU、操作系统，有没有安装 Python？这些工作是谁做的？
2. 用动画“Serverless 与云服务器费用对比”估算：如果这个函数每天被调用 100 万次，用函数计算还是云服务器更省钱？

## 原书实训活动 { #book-practice }

下面是纸质教材本章的实训活动。实验 5-1 完成了“技术实践”中的无服务器函数部分，实验 4-2 完成了容器部署部分；技术与职业调研、职业规划可结合 5.2 节和下面的“职业规划模板”完成。

题目：探索云计算前沿技术与职业发展路径。

1. 实训目标

（1）了解云计算前沿技术 (无服务器计算、边缘计算、人工智能与大模型) 的应用场景与优势。

（2）探索云计算领域的职业发展机会，明确不同职业角色的技能要求。

（3）通过实际操作和调研，制定个人职业发展规划。

2. 实训步骤

（1）技术与职业调研。

研究无服务器计算、边缘计算、人工智能与大模型在行业中的应用案例。

收集云计算职业信息，包括云架构师、云运维工程师、DevOps 工程师、云计算产品售后工程师等角色的职责和技能要求。

（2）技术实践。

搭建无服务器计算环境（如 AWS Lambda 或阿里云函数计算），编写并测试一个简单的无服务器函数。

使用容器技术（如 Docker 和 Kubernetes）部署一个小型 Web 应用。

模拟边缘计算场景，使用 Raspberry Pi 或其他边缘设备进行数据采集和预处理。

（3）职业规划制定。

根据调研结果和实践体验，分析自身兴趣与技能，确定适合的云计算职业方向。制定短期和长期职业发展目标，包括要获取的云计算认证（如 AWS Certified Solutions Architect、阿里云认证等）和需要提升的技能。

3. 实训总结

（1）撰写实训报告，总结对云计算前沿技术的理解、实践经验以及职业规划。

（2）进行小组汇报，分享实训成果和职业规划思路。
