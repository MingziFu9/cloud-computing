# 第 2 章 云计算核心技术

!!! abstract "本章学时"
    理论 11 学时（线上 8 + 线下 3）· 实验 3 学时

信息技术是推动经济社会发展、实现科技自立自强的关键。近年来，我国在云计算技术领域已取得显著成就。《中华人民共和国国民经济和社会发展第十四个五年规划和 2035 年远景目标纲要》明确指出要加快数字化发展，加快推动数字产业化，推进产业数字化转型。本章聚焦云计算核心技术展开深入讲解，涵盖虚拟化技术、分布式存储技术、分布式计算技术、云网络技术、云安全技术及桌面云技术等知识。

## 学习目标

**知识目标**

1. 掌握虚拟化技术。

2. 掌握分布式存储技术。

3. 了解分布式计算技术。

4. 掌握虚拟网络、私有网络及弹性 IP 等技术。

5. 了解云安全技术。

6. 掌握桌面云技术。

**技能目标**

1. 具备虚拟化技术的基础能力。

2. 能够掌握分布式存储技术、云网络技术的结构及操作。

3. 能够部署和设计简单的桌面云系统。

**素养目标**

培养学生的工匠精神，以及做事严谨、精益求精、着眼细节、爱岗敬业的职业精神；引导学生以科技报国之志，扎实掌握云计算的核心技术，为我国建成科技强国、网络强国贡献自己的力量。

## 案例导入

!!! example "案例导入：亚马逊的转型之路———云计算核心技术应用案例"

    亚马逊作为全球电商巨头，业务高速增长使其面临促销期流量激增导致的服务器崩溃风险、海量数据管理成本高昂以及传统 IT 架构难以快速响应市场变化等挑战。为此，亚马逊深度应用云计算核心技术，成功实现业务全面升级。

    在技术层面，亚马逊运用虚拟化技术将物理服务器转化为多个虚拟机，依据促销季流量需求灵活调整虚拟机数量，高效分配资源，降低成本。同时，将电商系统拆分为用户、订单、商品等微服务，借助容器化技术独立部署，实现高可用与快速迭代，加速新功能上线。借助弹性计算功能和分布式计算技术，亚马逊可依实时流量自动调整资源，提升系统响应速度。在数据存储上，利用云存储服务保存各类数据，通过 CDN 优化访问体验。

    在云安全方面，亚马逊构建了坚固的防护体系。采用多层次身份认证机制，部署实时入侵检测系统与防火墙，运用数据加密技术保障数据安全，并定期进行安全漏洞扫描与渗透测试，确保业务连续性。

    为提升运维效率，亚马逊引入自动化管理工具与 DevOps 实践，减少人为失误，实现软件自动部署、更新与运维。借助大数据分析工具和数据湖仓一体化架构，精准把握用户偏好，实现个性化推荐。此外，基于云桌面技术，员工可远程接入虚拟桌面环境，提高办公灵活性，IT 部门也可通过集中管理镜像与应用，简化桌面维护，降低运维成本。

    技术应用成效显著：网站在促销期保持流畅，用户购物体验提升；IT 资源利用率提高超 40%，成本降低；新业务上线周期缩短 60%；强大的数据处理与分析能力助力科学决策，推动销售额增长。亚马逊凭借云计算技术成功巩固行业领先地位，其转型为全球电商企业提供了标杆范例，彰显了云计算技术在电商领域的巨大价值。
