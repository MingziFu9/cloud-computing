# 3.2 IaaS 层服务 {#32}

!!! info "学前导读"

    IaaS 层服务就是云上的“毛坯房”：给你一台云服务器、一块云硬盘、一个存储桶，装修（装系统、装软件）由你自己来。本节按“买服务器、存文件、用数据库”的顺序，讲阿里云等平台上最常用的三类 IaaS 及相关服务：

    1. **云服务器**（3.2.1.1）：创建、登录、监控、扩缩容、安全和费用管理七个环节；
    2. **云存储**（3.2.1.2）：以对象存储为例，从选服务商到上传、分享、同步、备份；
    3. [**云数据库**](../../appendix/glossary.md#g-云数据库 "由云平台负责安装、备份、高可用等运维工作的托管数据库服务"){ .term }（3.2.2）：MySQL、SQL Server、PostgreSQL 版的使用和日常管理。

    严格地说，云数据库 RDS 已经替用户管好了数据库软件，更接近 PaaS，本书按纸质教材的安排放在这一节。本节的动手内容在[实验 3-1](labs.md#3-1)。

## 3.2.1 云服务器与云存储 {#321}

### 3.2.1.1 云服务器 {#3211}

#### 1. 创建云服务器

选择云服务提供商：选择一个可靠的云服务提供商，如阿里云、AWS、Azure、Google Cloud 等。

登录控制台：注册并登录云服务提供商的管理控制台。

#### 2. 选择 ECS 实例

在控制台中，找到“ECS”或“计算”相关的选项，单击进入。

配置实例如下。

选择镜像：选择操作系统镜像（如 Linux 或 Windows）。

选择实例规格：根据需求选择 CPU、内存等配置。

存储配置：选择云盘类型（如 SSD 或 HDD）和大小。

网络配置：选择或创建虚拟私有云（VPC）和子网，配置安全组。

设置登录凭证：选择 SSH 密钥对或设置密码，用于后续登录。

确认并创建：检查配置，确认无误后单击“创建”。

获取实例信息：创建完成后，记录实例的 IP 地址、登录凭证等信息。

#### 3. 登录云服务器

使用 SSH 工具（如 PuTTY、Terminal 等）通过 IP 地址和凭证登录云服务器。

更新系统：定期更新操作系统和软件包。

安装软件：根据需求安装所需的软件和服务（如 Web 服务器、数据库等）。

配置防火墙：确保安全组和防火墙规则正确设置，限制不必要的访问。

#### 4. 监控与维护

使用云服务提供商提供的监控工具，监控 CPU、内存、网络流量等性能指标。定期备份数据，确保数据安全。

#### 5. 扩展与缩减

根据业务需求，随时调整 ECS 实例的规格（如升级 CPU、内存）或增加新的实例。

#### 6. 安全管理

定期检查安全组规则，确保只允许必要的流量。使用强密码和 SSH 密钥，定期更换密码。

#### 7. 费用管理

定期查看使用情况和费用，合理控制成本，选择合适的计费方式（按需计费或包年、包月）。

### 3.2.1.2 云存储 {#3212}

云存储（object storage service，OSS）是一种基于对象存储的服务，广泛用于数据的存储和管理。它具有高可靠性、高可用性和高扩展性等特点，适用于备份、归档、内容分发、数据共享等多种场景。以下是云存储的使用方法和基本步骤。

#### 1. 基础准备

（1）服务商选择。根据业务需求评估服务商特性：

①数据敏感性：选择支持端到端加密（如 AWS S3 CSE）。

②扩展性需求：优先选择支持横向扩展存储池的产品（如华为 OBS）。

③合规要求：医疗、金融行业需选择通过 HIPAA、等保三级认证的平台（如阿里云 OSS）。

（2）账户配置。多层级权限体系：

①创建主账号与子账号，通过 RBAC 分配权限（如开发组仅限读写指定 Bucket）。

②启用 MFA 多因素认证，降低账号被盗用的风险。

#### 2. 核心功能操作

（1）数据上传与管理。

①大文件优化：使用分片上传（Multipart Upload）技术，单文件最大支持 5 TB（如腾讯云 COS）。

②启用断点续传，避免网络中断导致重传。

（2）智能分层策略。设置生命周期规则，自动将 30 天未访问文件转存至低频存储，60 天后归档至冷存储（成本降幅达 70%）。

#### 3. 共享与协作

（1）安全共享：生成带有效期（最长 7 天）和下载次数限制（如 100 次）的加密链接。对敏感文件设置 IP 白名单，仅限特定地址访问。

（2）协同办公：集成在线 Office 套件（如金山文档、OnlyOffice），实现多人实时编辑与版本追踪。

#### 4. 同步与备份

（1）客户端部署：安装同步客户端，设置双向同步文件夹（如 Dropbox 的 Smart Sync），本地仅保留缩略图。

（2）自动化备份：配置定时任务，每日凌晨备份数据库至独立 Bucket，保留最近 7 天快照。

#### 5. 高级功能应用

（1）内容分发加速：结合 CDN 服务，将静态资源（如图片、视频）缓存至全球边缘节点，用户访问速度提升 3~5 倍。

（2）通过 URL 鉴权防止盗链，设置 Referer 白名单限制访问来源。

（3）数据处理与分析：图片处理：使用存储服务内置的图像处理功能（如阿里云 OSS 的 img 参数），自动生成缩略图、水印。

（4）日志分析：通过 AWS Athena 直接查询存储在 S3 中的日志文件，无须数据迁移。

**说明**

案例：某在线教育平台。

场景：日新增课程视频 200 GB，需支持全球学员流畅访问。

措施：存储分层：原始视频存于归档存储，转码后高清版放低频存储，缩略图放标准存储。CDN 加速：配置全球 300+节点加速，首屏加载时间从 8 s 降至 1.2 s。

自动化处理：上传视频后触发 Lambda 函数自动转码、截图、生成字幕。

成效：存储成本降低 40%，带宽费用下降 35%，用户留存率提升 18%。

## 3.2.2 云数据库的使用与管理 {#322}

### 3.2.2.1 云数据库的使用 {#3221}

阿里云关系数据库 RDS 基于阿里云分布式文件系统和高性能存储，提供了容灾、备份、恢复、监控、迁移等方面的全套解决方案，彻底解决了数据库运维的烦恼。阿里云关系数据库 RDS 包含 MySQL、SQL Server、PostgreSQL、PPAS 和 OSQL 五种存储引擎，可以方便快捷地创建适合用户应用场景的数据库实例。

#### 1. 云数据库 MySQL 版

云数据库 MySQL 版基于阿里巴巴的 MySQL 源码分支，经过“双 11”高并发、大数据量的考验，拥有优良的性能。云数据库 MySQL 版支持实例管理、账号管理、数据库管理、备份恢复、白名单、透明数据加密以及数据迁移等基本功能。除此之外还提供以下高级功能。

（1）只读实例：在对数据库有大量读请求和少量写请求时，单个实例可能无法承受读取压力，为了实现读取能力的弹性扩展，减少单个实例的压力，云数据库 MySQL5.6 版的实例支持只读实例，利用只读实例满足大量的数据库读取需求，以此增加应用的吞吐量。

（2）Cloud DBA 数据库性能优化：针对 SQL 语句性能、CPU 使用率、IOPS 使用率、内存使用率、磁盘空间使用率、连接数、信息、热点表等，Cloud DBA 提供了智能的诊断及优化功能，能最大限度地发现数据库存在的或潜在的健康问题。Cloud DBA 的诊断基于单个实例，会提供问题详情及相应的解决方案，为用户维护实例带来极大的便利。

（3）数据压缩：云数据库 MySQL5.6 版本支持通过 Toku DB 存储引擎压缩数据。大量的测试表明，数据表从 Inno DB 存储引擎转到 Toku DB 存储引擎后，数据量可以减少 80% ~ 90%，即 2 TB 的数据量能压缩到 400 GB 甚至更低。除了数据压缩，Toku DB 存储引擎还支持事务和在线 DDL 操作，可以很好地兼容运行于 My ISAM 或 Inno DB 存储引擎上的应用。

#### 2. 云数据库 SQL Server 版

云数据库 SQL Server 版不仅拥有高可用架构和任意时间点的数据恢复功能，强力支撑各种企业应用，而且包含了微软的 License 费用，减少了额外支出。云数据库 SQL Server 版支持实例管理、账号管理、数据库管理、白名单、备份恢复、透明数据加密以及数据迁移等基本功能。

#### 3. 云数据库 PostgreSQL 版

PostgreSQL 是全球最先进的开源数据库，其优点主要是能够完整实现 SQL 规范以及支持丰富多样的数据类型（包括 JSON 数据、IP 数据和几何数据等）。除了完美支持事务、子查询、多版本控制（MVCC）、数据完整性检查等特性，云数据库 PostgreSQL 版还集成了高可用和备份恢复等重要功能，减轻用户的运维压力。

### 3.2.2.2 云数据库的管理 {#3222}

用户管理：创建和管理数据库用户，配置权限和访问控制，确保只有授权用户能够访问敏感数据。

数据库维护：定期进行数据库维护，如执行索引重建、数据清理、升级数据库版本等，以保持数据库的健康和性能。

安全管理：定期更新数据库安全补丁，使用加密技术保护数据传输和存储，确保数据库的安全性。

故障排除：监控数据库日志，分析错误信息，及时处理性能瓶颈和故障，确保数据库的高可用性。

成本管理：定期评估使用情况，优化资源配置，避免不必要的开支，利用云服务提供的计费和成本管理工具进行监控。

文档与培训：维护数据库使用和管理的文档，定期对团队进行培训，提高团队对云数据库的理解和使用能力。

云数据库为用户提供了高效、灵活和可扩展的数据库解决方案。用户通过合理地使用与管理，可以充分发挥云数据库的优势，提升业务的运作效率和数据安全性。
