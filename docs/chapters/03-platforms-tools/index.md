# 第 3 章 云计算平台与工具

!!! abstract "本章学时"
    理论 4 学时（线上 3 + 线下 1）· 实验 2 学时

在当今数字化加速演进的时代，技术创新成为推动社会前行的核心引擎，而云计算技术正是其中的关键力量。云计算平台与工具是实现云计算技术的核心载体，能够为云用户构建一个高效、灵活且易于管理的基础设施框架，并提供全方位技术支持。IaaS 为企业提供基础的计算、存储和网络资源，降低硬件采购与维护成本；PaaS 为开发者打造集成化的开发与运行环境，加速应用开发；SaaS 则以订阅模式提供丰富多样的软件应用，用户无须自行安装和维护。本章聚焦于云计算平台与工具，以主流云服务平台为切入点，深入剖析 IaaS 层服务、PaaS 层服务、SaaS 层服务等相关内容。

## 学习目标

**知识目标**

1. 了解主流云服务平台的基础知识。

2. 掌握阿里云、腾讯云、华为云、信服云等相关内容。

3. 掌握 IaaS 层服务的创建与管理。

4. 掌握 PaaS 层服务的使用。

5. 了解 SaaS 层服务的模式与使用。

6. 了解自动化与 DevOps 的使用。

**技能目标**

1. 能够操作和使用主流公有云平台的虚拟机。

2. 具备自动化运维的能力。

**素养目标**

培养学生良好的学习习惯；培养学生的工匠精神，以及做事严谨、精益求精、着眼细节、爱岗敬业的职业精神；引导学生树立团队互助、合作进取的意识。

## 案例导入

!!! example "案例导入：企业云上自动化运维工具的应用案例"

    某制造企业“精工制造”在数字化转型过程中，传统运维方式成为发展的瓶颈———服务器配置复杂且易出错，软件更新耗时费力，难以满足企业高效灵活的 IT 需求。为了解决这些问题，企业决定借助云计算平台与自动化运维工具进行全面优化。

    企业在阿里云平台进行部署，利用其弹性计算服务和对象存储服务，确保有足够的计算资源和安全可靠的数据存储。企业通过 Ansible 实现自动化配置管理，运维人员编写 Playbook 文件定义服务器配置，批量部署配置服务器，确保测试、生产环境一致性，新服务部署时间大幅缩短；采用 Jenkins 搭建 CI/CD 流程，开发人员提交代码后自动触发构建、测试和部署任务，实现软件快速迭代更新；利用 Prometheus 和 Grafana 进行监控与可视化，Prometheus 收集服务器和应用性能指标，Grafana 将数据可视化，帮助运维人员实时了解系统运行状况，及时发现并解决问题。

    在具体应用中，Ansible 完成服务器初始配置和软件安装；Jenkins 实现自动化构建、测试和部署流程；Prometheus 监控系统性能指标，Grafana 提供直观图表展示。代码更新出现错误时，企业可以借助 Jenkins 的回滚功能快速恢复稳定版本。在业务高峰时，企业可以结合阿里云的弹性伸缩功能，自动增加 ECS 实例应对高负载，避免系统崩溃。

    此外，企业利用阿里云日志服务收集和分析日志信息，与 Prometheus 和 Grafana 集成，构建全面监控体系，提升故障排查效率和系统可靠性。

    通过这些自动化运维工具与云计算平台的结合，“精工制造”有效解决了传统运维的难题。运维工作效率显著提升，配置管理更高效，软件更新更顺畅；运维质量与系统可靠性大幅提高，错误率降低，潜在风险能够被及时发现并处理；企业数字化转型得到有力支持，具备更强的竞争力和创新能力。

读完案例，想一想：“精工制造”用到的阿里云 ECS、OSS 分别属于哪一层服务？Ansible、Jenkins、Prometheus、Grafana 各自负责什么？学完 3.2 节和 3.5 节再回来对照。
