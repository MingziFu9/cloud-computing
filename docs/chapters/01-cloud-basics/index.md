# 第 1 章 云计算基础

!!! abstract "本章学时"
    理论 5 学时（线上 4 + 线下 1）· 实验 1 学时

目前，云计算技术已成为推动社会经济发展和产业数字化转型的关键技术。它兴起于技术进步与全球资源共享的时代背景下，既是技术发展的必然产物，也是时代发展的内在要求。国务院在《“十四五”数字经济发展规划》中提出大力推进产业数字化转型，推行普惠性“上云用数赋智”服务，推动企业上云、上平台，凸显了云计算技术在企业数字化转型中的重要地位。本章将对云计算的定义与特点、核心概念、服务模式等进行深入探讨，同时阐述云计算的历史、演进历程与发展趋势。

## 学习目标

**知识目标**

1. 了解云计算的定义与特点。

2. 掌握虚拟化、分布式计算、资源调度等核心概念。

3. 掌握 IaaS、PaaS、SaaS 服务模式的基本概念。

4. 了解云计算的历史、演进历程与发展趋势。

5. 了解云计算技术主要的应用场景。

6. 掌握国内外主流云平台的对比情况。

**技能目标**

1. 能够理解并掌握云计算的定义、概念和特点，能够准确区分云计算与其他传统计算模式的差异，阐明云计算技术在按需自助服务、广泛的网络访问、快速弹性伸缩、资源池化、快速灵活部署等方面的核心优势。

2. 能够描述云计算技术在当今社会各行业的典型应用场景，如互联网、金融、医疗、教育、制造业等，分析云计算技术对各行业业务模式创新、运营效率提升等方面的积极影响。

3. 学会分析云计算技术面临的常见挑战和问题，如安全性、可靠性、数据隐私、性能优化等，初步了解解决这些问题的基本思路和方法，为后续深入学习云计算技术奠定基础。

**素养目标**

培养学生的社会责任感与使命感，使其通过学习掌握专业知识；培养学生的求真求实意识，引导其积极探索实践；培养学生的创新精神与科学思维，提升其解决实际问题的能力；激发学生的爱国热情与创新动力，为个人成长奠定基础。

## 案例导入

!!! example "案例导入：“某云店”电商企业云计算技术应用案例"

    “某云店”是一家主营潮流服饰的小型电商企业，在发展过程中，通过在不同阶段采用云计算技术的三种服务模式，利用新技术进行业务创新，实现业务的高效拓展与成本控制。

    在创业初期，“某云店”资金有限且无法预估市场需求，为快速建设线上销售平台，企业选择阿里云 ECS 实例（infrastructure as a service，IaaS，基础设施即服务）。公司的 IT 技术人员根据需求，在控制台轻松配置中央处理器（central processing unit，CPU）、内存、存储资源，申请 2 核 4 GB 内存、50 GB 存储的服务器，用于部署网站程序和数据库。相比自建机房需投入服务器采购、场地租赁、电力维护等费用，这种模式极大降低了前期成本。同时，当促销活动带来流量高峰时，可一键扩容服务器配置，轻松应对流量波动。

    随着业务增长，“某云店”计划推出促销活动小程序吸引客户。企业利用 Google App Engine（platform as a service，PaaS，平台即服务）平台，开发人员无须关注服务器配置、操作系统安装等底层工作，直接在平台提供的 Python 开发环境中编写代码，并使用内置的数据库存储用户信息和商品数据。原本需要一个月开发的小程序，在 PaaS 平台的助力下，仅用两周就上线了，节省了大量时间与人力成本。

    公司规模扩大后，订单量激增，商品管理、客户服务等工作变得复杂。“某云店”采用“网店管家云端版”（software as a service，SaaS，软件即服务）电商管理软件，无须安装任何程序，注册账号后，登录网页即可使用。员工通过网店管家后台，快速上架商品、处理订单，利用内置的客服系统及时回复客户咨询。系统还提供数据分析功能，帮助企业了解销售趋势。

读完案例，先在心里回答一个问题：“某云店”三个阶段分别用了哪种服务模式？每一阶段它自己还要管哪些事？学完 [1.1.3 云计算的服务模式](1-1.md#113) 再回来对照。
