## 实验 1-1 ★ 注册云平台、逛控制台、算一算价格 { #1-1 }

**实验目的**

1. 亲眼看一看真实的云平台长什么样，认出控制台里的“计算、存储、网络、数据库”几大类产品（对应 [1.1.3.1](1-1.md#1131)）；
2. 用价格计算器比较“按量付费”和“包年包月”，体会 [1.1.1.2](1-1.md#1112) 中“服务可被测量、按需付费”的含义；
3. 对照 [表 1-7](1-2.md#1221)，说出一两个国内云平台的产品名称。

**实验环境**

- 运行环境：**浏览器**。电脑或手机均可，推荐电脑。
- 平台：阿里云（[www.aliyun.com](https://www.aliyun.com)）。也可以换成腾讯云、华为云，步骤大同小异。
- 费用：0 元。本实验只浏览、只试算，**不点“立即购买”**。

**实验数据**：无。

**实验步骤与代码**

1. **注册并实名认证**。打开阿里云官网，点右上角“免费注册”，用手机号注册。云平台开通产品前需要实名认证，按提示用支付宝或身份证完成个人实名认证即可。
2. **进入控制台**。登录后点右上角“控制台”。控制台是管理所有云资源的“总开关”，左侧（或“产品与服务”菜单）按类别列出了全部产品。
3. **找四类产品**。在“产品与服务”里依次找到下面四个产品，记下它们属于哪一类，填入实验记录表：
    - 云服务器 ECS（弹性计算服务）
    - 对象存储 OSS
    - 专有网络 VPC
    - 云数据库 RDS
4. **看一看 ECS 的购买页**。进入“云服务器 ECS”，点“创建实例”。不要提交订单，只观察页面上要选的内容：付费类型（包年包月 / 按量付费 / 抢占式实例）、地域和可用区、实例规格（几核几 GB）、镜像（操作系统）、存储（系统盘大小）、带宽。把这些选项和 [1.1.3.1](1-1.md#1131) 中“IaaS 的基本功能”对应起来。
5. **用价格计算器试算**。在购买页右下角或官网“价格计算器”中，选同一配置（例如 2 核 4 GB、40 GB 系统盘、1 Mbit/s 带宽、华南 1 广州地域），分别记下：
    - 按量付费的“每小时”价格；
    - 包年包月的“1 个月”价格。
6. **算一算**。把按量付费的每小时价格乘以 24 × 30，得到“连续开一个月”的按量价格，和包年包月对比；再假设只在每天晚上 8 点到 12 点用 4 个小时，重新计算按量付费的月费用。
7. **退出**。确认没有创建任何实例（ECS 控制台的“实例”列表应为空），退出登录。

!!! warning "待实测"
    编者编写本实验时所在的环境无法访问阿里云网站，以上步骤按阿里云公开文档整理，页面名称和价格以实际页面为准；云厂商经常调整页面布局和价格，找不到某个按钮时，在控制台顶部的搜索框里搜产品名即可。任课教师上课前请实际走一遍，把截图和价格补进下面的记录表示例。

**常见问题排查**

| 现象 | 原因与处理 |
|---|---|
| 注册时收不到验证码 | 检查手机号是否已注册过；稍等 1 分钟再试。 |
| 进入购买页要求实名认证 | 云平台规定开通产品前必须实名，按提示完成个人认证即可，不收费。 |
| 价格计算器里价格显示“0 元” | 可能选中了“免费试用”或新人活动配置，换一个普通配置再算。 |

**思考与练习**

1. 如果“某云店”的网站白天 8 小时访问量大、夜里几乎没人访问，你会建议它用哪种付费方式？为什么？
2. ECS 购买页上，哪些选项属于“计算”，哪些属于“存储”，哪些属于“网络”？

## 实验 1-2 ★ 服务模式与部署模式对号入座 { #1-2 }

**实验目的**

1. 能根据“用户自己要管什么”判断一项服务属于 IaaS、PaaS 还是 SaaS（对应 [1.1.3](1-1.md#113)）；
2. 能根据“谁拥有、谁使用”判断一个云属于公有云、私有云、混合云还是社区云（对应 [1.1.4](1-1.md#114)）。

**实验环境**

- 运行环境：**浏览器**，直接在本页下方的练习区操作，手机上点选也可以完成。
- 费用：0 元。

**实验数据**：练习区内置 16 张卡片，每张写着一个真实或常见的云服务场景。

**实验步骤与代码**

1. 先在“服务模式”一栏，把每张卡片拖到（手机上是先点卡片、再点格子）IaaS、PaaS、SaaS 三个格子之一。
2. 全部放好后点“检查”。放错的卡片会变红，并显示提示。根据提示改正，直到全部正确。
3. 切换到“部署模式”一栏，用同样的方法把卡片放进公有云、私有云、混合云、社区云四个格子。
4. 点“看我的成绩”，把两栏第一次检查时的正确数记入记录表。

**运行结果**

全部放对后，页面会显示“全部正确”。下面是参考答案中容易混淆的几张卡片：

| 卡片 | 答案 | 理由 |
|---|---|---|
| 在云上租一台 2 核 4 GB 的虚拟机，自己装 MySQL | IaaS | 操作系统和数据库软件都要自己装和维护。 |
| 直接买一个云数据库 RDS 实例，只管建表写数据 | PaaS | 数据库软件的安装、备份、升级由云服务商负责。 |
| 用钉钉开视频会议 | SaaS | 软件是现成的，用户只是使用者。 |
| 银行核心交易系统在自己的机房，手机银行活动页放在公有云 | 混合云 | 私有云和公有云组合使用。 |
| 某省各级政府部门共用的政务云 | 社区云 | 面向有共同目标的一群用户（各级政府部门）。 |

**常见问题排查**

| 现象 | 原因与处理 |
|---|---|
| 手机上拖不动 | 改用“先点卡片、再点格子”的方式。 |
| 分不清 PaaS 和 SaaS | 问自己一句：“我是在**开发**一个应用，还是在**使用**一个应用？”开发用的是 PaaS，直接使用的是 SaaS。 |
| 分不清私有云和社区云 | 看用户是“一个组织”还是“多个有共同目标的组织”。 |

**思考与练习**

1. “某云店”的案例中，三个阶段分别用了哪种服务模式？
2. 你所在的学校、单位用到了哪些云服务？它们属于哪种服务模式和部署模式？

## 原书实训活动 { #book-practice }

下面是纸质教材本章的实训活动，作为课后拓展，可在线下课上分组交流。

题目一：云计算的服务模式与部署模式的对比分析。

要求：学生通过查阅资料、实际操作云平台等方式，详细了解 IaaS、PaaS、SaaS 三种服务模式，以及公有云、私有云、混合云等部署模式的特点、优势和适用场景；以表格或图表的形式进行对比分析，并撰写一篇简短的分析报告，总结不同服务模式和部署模式的异同点和应用场景。

题目二：云计算的发展趋势预测与讨论。

要求：学生分组，每组根据所学的云计算发展趋势知识，结合当前云计算行业的最新动态和研究成果，对未来 3~ 5 年内云计算的发展趋势进行预测和讨论。每组推选代表发表小组观点，并与其他小组进行交流和辩论。教师负责引导学生对云计算前沿技术进行关注和思考，培养学生的分析、预测和沟通能力。
