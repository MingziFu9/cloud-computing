## 课程描述

本课程介绍云计算的基本原理、架构和技术，内容包括云计算基础概念、云计算架构与模型、云计算平台与工具、云存储与数据库、云计算服务与应用开发，以及云计算的最新发展趋势和实践案例。课程以阿里云等主流云平台为例，通过交互动画、网页实验和课程项目实践，让学生掌握云计算平台的部署与管理、数据存储与处理、服务与应用开发等技能，培养团队合作能力。

## 学习目标

学完本课程，学生应能够：

1. 说出云计算的定义、特点、服务模式和部署模式，理解虚拟化、分布式存储、分布式计算、云网络、云安全和桌面云等核心技术的基本原理；
2. 在主流云平台上注册和管理账号，选择合适的计费模式，创建和使用云服务器、对象存储、云数据库等服务；
3. 使用 Docker、Docker Compose 等工具在云上部署网站和容器应用，了解自动化运维和 CI/CD 流水线；
4. 结合政务、电商、教育、医疗、制造等行业案例，说明云计算解决了什么问题；
5. 了解边缘计算、Serverless、大模型等发展趋势，以及云计算相关岗位、认证和职业道德要求。

## 考核方式

- **过程性考核（50%）**：线上学习进度与随堂小测、课堂练习与讨论、课后练习、实验报告；
- **期末考试（50%）**：闭卷，题型为单选题、多选题、判断题和简答题，可用[模拟卷](mock-exam.md)复习。
