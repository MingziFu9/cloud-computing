## 课程与学习方法 { #faq-1 }

??? question "网络版和纸质教材有什么不同？"

    正文、章节结构和节号与纸质教材一致。网络版增加了每节的“学前导读”、19 个交互动画、随堂小测、13 个网页实验和每章约 21 道课后练习（纸质教材的思考与练习不再使用）。少量明显的笔误和过时信息在网络版中已直接改正，改了哪些见[网络版与纸质版对照](../errata.md)。

??? question "没有学过编程，能学好这门课吗？"

    能。本课程重在理解云计算的概念和会用云服务，不要求编程。实验中用到的 Python、PHP 代码都已写好并带注释，看懂注释、照着运行即可；需要的 Linux 命令在[附录 B](../appendix/b-commands.md)里有速查表。

??? question "书上标着“待实测”的实验步骤是什么意思？"

    这些步骤需要登录阿里云控制台，编者的编写环境无法访问阿里云，所以依据阿里云公开文档编写，没有截图。命令行和代码部分编者都实际运行过。控制台界面经常改版，如果和书上描述的菜单名称不一致，以控制台实际显示为准。

??? question "第 2 章内容特别多，怎么学？"

    第 2 章占全书四成篇幅，是本课程的核心，分配了 14 学时。建议先看每节的“学前导读”，弄清哪些是重点、哪些只需了解；标为“拓展阅读”的折叠内容可以跳过；然后配合动画理解虚拟化、存储、网络等抽象概念。见[第 2 章首页](../chapters/02-core-technologies/index.md)。

## 概念辨析 { #faq-2 }

??? question "IaaS、PaaS、SaaS 到底怎么区分？"

    看“用户要自己管到哪一层”：IaaS 给你一台空服务器，操作系统以上都要自己装；PaaS 连运行环境都准备好了，你只管写代码和部署；SaaS 是现成的软件，打开就用。可以用动画“服务模式责任分层”切换对比。见 [1.1.3](../chapters/01-cloud-basics/1-1.md#113)。

??? question "虚拟机和容器有什么区别？"

    虚拟机虚拟出一整台计算机，每台都有自己的操作系统，隔离性强但占资源多、启动慢；容器共享宿主机的操作系统内核，只打包应用和依赖，启动只要零点几秒，一台服务器能跑很多个。实验 2-2 实测一个 Nginx 容器只占约 5 MB 内存。见 [2.1.2](../chapters/02-core-technologies/2-1.md#212)。

??? question "对象存储、文件存储、块存储分别适合什么？"

    对象存储适合图片、视频、备份等海量非结构化数据，通过网址访问；文件存储像一个共享文件夹，适合多台服务器共用文件；块存储像一块硬盘，挂在云服务器上装系统和数据库。见 [2.2.2](../chapters/02-core-technologies/2-2.md#222) 和动画“三种存储怎么存”。

??? question "安全组和防火墙是一回事吗？"

    安全组可以理解为云服务器的“虚拟防火墙”，作用在实例级别，用入方向、出方向规则控制流量。新建的云服务器默认不放行 80 端口，所以搭网站时一定要添加规则。见 [2.5 节](../chapters/02-core-technologies/2-5.md) 和动画“安全组规则试验台”。

??? question "持续交付和持续部署有什么区别？"

    两者都会把测试通过的代码自动部署到测试环境；区别在最后一步：持续交付上生产环境前要人工批准，持续部署则全自动上线。可以在动画“CI/CD 流水线”里勾选“生产部署需人工审批”对比。见 [3.5.2](../chapters/03-platforms-tools/3-5.md#352)。

??? question "Serverless 是真的没有服务器吗？"

    不是。服务器仍然存在，只是由云平台负责部署、运维和伸缩，开发者看不到也不用管。它按调用次数和执行时间计费，没有请求就不收费。见 [5.1.3](../chapters/05-trends-careers/5-1.md#513)。

??? question "边缘计算会取代云计算吗？"

    不会。边缘计算负责就近、实时的处理，云计算负责全局分析、模型训练和长期存储，两者是“云边协同”的关系。见 [5.1.1](../chapters/05-trends-careers/5-1.md#511) 和动画“边缘计算与云端计算对比”。

## 实验环境与费用 { #faq-3 }

??? question "做实验要花钱吗？"

    大多数实验可以不花钱：阿里云“云起实验室”提供免费的实验沙箱，新用户还有免费试用额度；Docker 类实验在自己电脑上做，完全免费。如果使用按量付费的云服务器，实验结束后务必**释放实例**，否则会持续计费。见[附录 A](../appendix/a-labs-env.md)。

??? question "自己的电脑需要什么配置？"

    做 Docker 实验（2-2、2-3、4-2）建议 8 GB 内存、Windows 10/11 或 macOS，安装 Docker Desktop；Moodle 实验（4-3）建议在云服务器上做。只用浏览器的实验（1-1、1-2、3-3、5-1）任何电脑都可以。见[附录 A](../appendix/a-labs-env.md)。

??? question "Docker 拉取镜像特别慢或者失败怎么办？"

    国内访问 Docker Hub 不稳定，可以配置镜像加速器，例如阿里云容器镜像服务 ACR 为每个用户提供的专属加速地址。配置方法见[附录 A.2](../appendix/a-labs-env.md#a2)。

??? question "没有自己的服务器，能做“在云服务器上……”的实验吗？"

    可以用三种方式：阿里云云起实验室的免费沙箱（实验结束自动回收）、新用户免费试用的云服务器，或者在自己电脑上用 Docker 运行一个 Ubuntu 22.04 容器代替（编者就是这样验证命令的，但公网访问和安全组部分无法体验）。

??? question "实验结束后要做哪些清理？"

    云上：释放云服务器、删除快照和存储桶里的文件、删除函数和触发器；本机：`docker compose down -v` 删除容器和数据卷，`docker image prune` 删除不用的镜像。

??? question "实验代码在哪里下载？"

    在本书 GitHub 仓库的 `labs/` 目录，按章分文件夹（`ch01`～`ch05`），依赖写在 `labs/requirements.txt` 里。

## 实验排错 { #faq-4 }

??? question "服务器上 curl 能访问，浏览器打不开网站？"

    九成是安全组没有放行 80 端口；其次检查是否写成了 `https://`（实验没有配置证书）。动画“云上网站的一次访问”演示了各种错误现象对应的原因。见[实验 3-1](../chapters/03-platforms-tools/labs.md#3-1)。

??? question "浏览器提示“连接超时”和“拒绝连接”有什么不同？"

    超时：请求被安全组静默丢弃了，检查安全组；拒绝：请求到了服务器但没有程序在监听这个端口，检查 Nginx/Apache 是否启动。

??? question "`docker: permission denied` 怎么办？"

    Linux 上普通用户默认没有 Docker 权限。用 `sudo docker ...`，或执行 `sudo usermod -aG docker $USER` 后重新登录。

??? question "端口被占用（port is already allocated）怎么办？"

    用 `docker ps` 找到占用端口的容器并 `docker rm -f` 删除，或者换一个宿主机端口（如把 `-p 4000:80` 改成 `-p 4001:80`）。

??? question "SSH 连不上云服务器？"

    检查三点：安全组是否放行 22 端口；用户名是否正确（Ubuntu 镜像有的是 `ubuntu`，有的是 `root`）；密码或密钥是否正确。也可以直接用控制台的“远程连接”功能登录。

## 职业与认证 { #faq-5 }

??? question "学完这门课可以考什么证？"

    本书内容覆盖阿里云 ACA（云计算助理工程师）、华为 HCIA-Cloud Computing、深信服 SCCA-C 等入门级认证的大部分基础知识。见 [5.2.2](../chapters/05-trends-careers/5-2.md#522)。

??? question "专科毕业生从什么岗位做起比较合适？"

    云运维工程师、云计算售后或技术支持是常见的起点，积累几年经验后可以向 DevOps 工程师、云架构师发展。见 [5.2.1](../chapters/05-trends-careers/5-2.md#521)。

??? question "还想继续深入学习，下一步学什么？"

    同学期的《大数据技术处理技术》会在 Hadoop 集群上真正运行 MapReduce 和 Spark；容器方向可以继续学 Kubernetes 并考 CKA；也可以在阿里云云起实验室里完成更多动手场景。
