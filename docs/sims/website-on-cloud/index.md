## 教学说明

**学习目标**

1. 能说出一次网页访问依次经过的云服务：DNS、安全组、云服务器、云数据库、对象存储（理解）；
2. 能根据浏览器的错误现象判断是哪个环节没有配好（应用）。

**画面与操作**

- “配置清单”是 4.1.1 节各步骤对应的配置清单，默认故意漏掉“安全组放行”和“SSL 证书”两项。
- 点“访问网站”，黄色圆点代表请求，经过的环节打 ✔，卡住的环节打 ✘；下方浏览器显示用户实际看到的页面或错误。

**数据来源**：错误提示取自 Chrome 浏览器、Nginx 和 PHP 的真实报错文字（如 `ERR_CONNECTION_TIMED_OUT`、`ERR_CONNECTION_REFUSED`）；网络拓扑为教学简化。

**课堂用法建议**

1. 先按默认配置访问，请学生根据“响应时间过长”判断原因；放行安全组后再访问，比较“超时”和“拒绝连接”的区别。
2. 与实验 4-1 结合：学生在真实服务器上遇到问题时，先对照本动画判断卡在哪一层。
