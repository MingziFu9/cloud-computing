## 教学说明

**学习目标**

1. 能说出“弹性扩展”和“服务可被测量、按需付费”的含义（理解）；
2. 能根据一天的访问量变化，判断自建与上云哪种更划算（应用）。

**画面与操作**

- 灰色柱子是每小时的访问量（单位千人），橙色横线是自建机房按高峰买好的服务器台数，蓝色折线是上云后每小时实际开的服务器台数。
- 拖动“高峰访问量”滑块，两条线和下方两笔费用随之变化。
- 勾选“突发流量”，下午 3 点的访问量超过预计高峰，自建机房扛不住的小时显示为红色柱子。

**数据来源**：访问量曲线是按电商网站“中午小高峰、晚上 8 点大高峰”的常见形状设定的示意数据；价格为示意值，不对应任何云厂商的真实报价。

**课堂用法建议**

1. 让学生找出“上云反而更贵”的情况（提示：全天访问量都很高时），引出包年包月和按量付费各自的适用场景，衔接实验 1-1。
2. 勾选突发流量，讨论“自建机房再多买几台行不行”，引出弹性扩展的价值。
