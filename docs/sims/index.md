# 交互动画

这些动画都是普通网页，不需要安装任何软件，也不需要联网调用接口，在电脑和手机浏览器上都能打开。每个动画都嵌在对应章节的正文里，也可以从这里单独打开，适合课堂演示。每个动画页面下方都有“教学说明”，写明学习目标、操作方法、数据来源和课堂用法建议。

| 第 1 章 | [按需付费与弹性伸缩](elastic-billing/index.md) | 比较自建机房按高峰配置和上云弹性伸缩两种做法的服务器数量、利用率和费用 |
