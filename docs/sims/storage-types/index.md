## 教学说明

**学习目标**

1. 能说出对象存储、文件存储、块存储组织数据的方式：扁平的对象、目录树中的文件、编号的块（理解）；
2. 能根据业务场景选择合适的存储类型（应用）。

**画面与操作**

- 三个标签切换存储类型，点“存入照片”看 cat.jpg 被怎样保存：对象存储中是一个带元数据和网址的对象；文件存储中是目录树里的一个文件，多台服务器共享；块存储中是若干个编号的块。
- 下方“小练习”有 4 个场景，点选存储类型后显示解析。

**数据来源**：示意数据。访问地址中的域名为示例域名，不对应真实服务。

**课堂用法建议**

1. 结合表 2-3（三种主要的分布式存储类型对比），让学生用自己的话总结三种存储的区别。
2. 让学生说出手机相册备份、公司共享盘、网游数据库分别更像哪种存储。
