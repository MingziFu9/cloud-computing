## 教学说明

**学习目标**

1. 能画出虚拟机和容器的层次结构，指出两者的关键区别：是否各自带一个完整的操作系统（理解）；
2. 能根据启动时间、资源占用和隔离性，说明各自适合的场景（分析）。

**画面与操作**

- 左边是虚拟机：硬件、Hypervisor 之上有 3 台虚拟机，每台都含“客户 OS + 库 + 应用”；右边是容器：硬件、宿主机操作系统、容器引擎之上有 3 个容器，每个只含“库 + 应用”。
- 点“启动 3 个应用”，进度条按 10 倍速播放两边的启动过程，并显示内存占用。
- 点任意一层，下方显示这一层的说明。

**数据来源**：容器一侧为编者在实验 2-2 中的实测数据（nginx:1.27-alpine 镜像 74.5 MB，单个容器内存约 5 MB，创建并运行一个容器约 0.34～0.47 秒）；虚拟机一侧为常见 Linux 虚拟机的典型值（每台客户操作系统按 512 MB 内存、启动 40 秒计），页面上已注明“典型值”。

**课堂用法建议**

1. 先让学生猜两边启动各需多久，再播放动画。
2. 讨论：既然容器这么快，为什么云服务商还在卖虚拟机？引出隔离性、安全性和运行不同操作系统的需求。
