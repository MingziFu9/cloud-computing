## 教学说明

**学习目标**

1. 能读懂一条安全组规则：协议端口 + 来源地址 + 允许（理解）；
2. 能为网站服务器设计符合“最小开放”原则的安全组规则（应用）；
3. 能指出“一键全开”这类配置的风险（评价）。

**画面与操作**

- 左侧最多 5 条“允许”规则，每条可启用或停用，可选择端口和来源；没有匹配任何规则的请求一律拒绝。
- 右侧 8 个访问请求实时显示“放行”或“拒绝”，括号中写着它“应放行”还是“应拦截”，不符合预期的标红。
- “推荐配置”给出一套正确答案；“一键全开”演示对所有地址开放全部端口的后果。

**数据来源**：示意数据。办公网 198.51.100.0/24 取自文档示例地址段；其他公网地址为举例，不针对任何真实主机。真实云平台的安全组还支持“拒绝”规则、优先级和出方向规则，本动画只演示最常用的入方向允许规则。

**课堂用法建议**

1. 初始状态（80 和 22 都对所有地址开放）有两处问题，让学生先找出来再修改。
2. 结合 2.5.2.4 节案例二和 2.5.2.3 节案例四，讨论为什么“为了方便”打开端口是最常见的安全隐患。
