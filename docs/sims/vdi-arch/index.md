## 教学说明

**学习目标**

1. 能说出 VDI、IDV、VOI/TCI 中桌面操作系统分别在哪里运行（理解）；
2. 能根据断网、移动办公、数据安全等需求选择桌面云架构（应用）。

**画面与操作**

- 上方三个按钮切换架构，示意图中蓝色方块表示“正在运行的 Windows 桌面”在服务器还是终端上。
- “断开网络”“换一台终端登录”“服务器故障”三个按钮模拟三种情况，终端屏幕和下方说明随之变化；“恢复正常”复原。

**课堂用法建议**

1. 给出三个场景（银行柜台、网络不稳定的乡镇学校机房、需要 3D 设计的设计院），让学生用动画验证后选择架构。
2. 讨论教材的结论：为什么云计算应用中仍以 VDI 架构为主。
