## 教学说明

**学习目标**

1. 能说明数据冗余的两种方式：多副本、纠删码（理解）；
2. 能比较两者的容错能力和空间利用率，解释对象存储常用纠删码的原因（分析）。

**画面与操作**

- 6 块硬盘，点击任意一块使其损坏，再点一次修好。
- “三副本”：数据 A、B 各存 3 份，分散在 6 块盘上，空间利用率 33%。
- “纠删码 4+2”：4 个数据块 D1～D4 加 2 个校验块 P1、P2，空间利用率 67%。损坏后，下方灰色区域列出用校验方程把丢失的块“解”回来的过程。

**数据来源**：为便于理解，数据块用小整数表示，校验块用两个线性方程计算（P1 = D1 + D2 + D3 + D4，P2 = D1 + 2D2 + 3D3 + 4D4）。真实系统使用里德-所罗门（Reed-Solomon）编码，在有限域上做运算，原理相同。

**课堂用法建议**

1. 让学生找出“三副本坏 3 块盘会丢数据”的组合，再在纠删码下坏 3 块盘对比。
2. 结合 2.2.2.1 节“MinIO（高性能 EC 编码）”的说法，讨论为什么海量对象存储更喜欢纠删码，而对性能要求高的块存储常用多副本。
