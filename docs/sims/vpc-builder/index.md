## 教学说明

**学习目标**

1. 能说出 VPC、子网（交换机）、私网 IP、弹性 IP、安全组之间的包含和依赖关系（理解）；
2. 能根据“访问失败”的提示判断缺了哪一块（分析）。

**画面与操作**

- 左侧是任务清单和操作按钮，右侧画出当前的网络结构：蓝色虚线框是 VPC，绿色虚线框是子网，里面是云服务器卡片。
- 不按顺序操作会得到提示，例如先建云服务器会提示“要放进某个子网”；子网网段选 10.0.1.0/24 会提示“不在 VPC 网段内”。
- “从公网访问”会按“弹性 IP → 安全组 → 服务器”的顺序检查，缺哪一步就在哪一步失败。
- 创建第二台服务器后，可以演示弹性 IP 换绑。

**数据来源**：示意数据。网段、私网 IP 为常见规划示例；弹性 IP 203.0.113.10 取自专供文档示例使用的地址段，不对应真实服务器。

**课堂用法建议**

1. 让学生故意跳过第 ④ 步或第 ⑤ 步去访问，读懂失败提示，再补上。
2. 与第 3 章实验 3-1、第 4 章实验 4-1 衔接：实际创建 ECS 时，控制台中“网络和安全组”一步就是在做这几件事。
