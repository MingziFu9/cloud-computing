## 教学说明

**学习目标**

1. 能说出 CI/CD 流水线的典型阶段：提交、构建、测试、部署测试环境、部署生产环境（记忆）；
2. 能解释流水线“失败即停止”的意义，区分持续交付与持续部署（理解）。

**画面与操作**

- 五个方框代表五个阶段，颜色表示状态：蓝色运行中、绿色成功、红色失败、橙色待审批、灰色未执行。
- “提交有错误的代码”模拟漏乘天数的错误，单元测试失败后流水线停止。
- 勾选“生产部署需人工审批”后，最后一步要点“批准上线”才执行。

**数据来源**：示例项目和测试用例与实验 3-3 的 `labs/ch03/lab3_3_ci_demo` 一致；测试失败时的提示 `assert 12.0 == 360.0` 是按错误写法 `0.5 × 24` 算出的结果。日志为简化示意。

**课堂用法建议**

1. 先提交正确代码，再提交有错误的代码，请学生说出流水线停在哪一步、为什么。
2. 勾选人工审批再提交一次，讨论银行、电商等业务更适合持续交付还是持续部署。
